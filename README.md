## 🏛️ 品牌故事與精神 (Brand Origin & Philosophy)

**雲杉長青**，是一棵從台中出發的技術大樹；**CEDAR PARTNERED**，則是這棵大樹向外伸展的英文識別，代表一個如雪松般穩健長壽、與企業並肩前行的技術夥伴。

- **Cedar (雪松)**：象徵堅固、長壽、高聳與不朽，常作為大型建築之頂樑主柱。
- **Partnered (結為夥伴)**：代表「已成為夥伴」，不是距離遙遠的外部供應商，而是與客戶站在同一側、共擔風險與成果的長期同盟。

在一個由 AI 重塑規則的時代，我們致力於做那一棵站得夠高、根扎得夠深，又能陪企業一起長青的技術之樹。
